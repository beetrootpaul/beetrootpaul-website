# beetrootpaul-website

Codebase of the beetrootpaul.com website

## Initial steps

```shell
nvm use
npm install
```

## Development

```shell
npm run dev -- --open
```

## Static build

```shell
npm run build
npm run preview -- --open
```

## Tests

```shell
npm test
```

or to update the reference screenshots:

```shell
npm test -- --update
```
